# QwikCap

QwikCap helps you copy information from PDF forms into a spreadsheet.
You check the suggested answers beside the original document before you export.
The app processes files on your computer.

[Download the app](https://github.com/pranavdabeast24/capitolinus-form-extraction/releases/tag/qwikcap-clean-outlines-2026-11-20) · [Try one patient](docs/SIH_CLINIC_WORKFLOW.md) · [Edit the software](docs/GETTING_STARTED.md)

## Use the app

1. Add the PDFs for one patient.
2. Check the patient's study ID.
3. Check each suggested answer against the source.
4. Correct mistakes and approve the patient row.
5. Match the fields to your spreadsheet columns.
6. Export an Excel or CSV file.

For the included clinic forms, select **Advanced > Form type > Read SIH clinic forms**.
The [walkthrough](docs/SIH_CLINIC_WORKFLOW.md) shows every step for patient `1031`.
For another layout, [choose your own fields](docs/CUSTOM_FORMS.md) and save a reusable form type.

## Before you start

- Downloads support Apple Silicon Macs and 64-bit Intel or AMD Windows computers.
- The sample packet contains fictional patients.
- Review every answer. Some fields need manual work or remain blank.
- Repeated visits in REDCap need an extra conversion before import.
- This is a research prototype. Read the [data limits](SECURITY.md) before using real records.
