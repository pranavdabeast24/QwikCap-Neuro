# Windows continuation, 2026-11-18

This is a concise project work record, not a verbatim chat export. The earlier
[conversation snapshot](CONVERSATION.md) retains its original capture scope.

The user's request was: “Can you make it wokr for windows too?”

The work produced a portable Windows x64 ZIP with Python and Tk included,
standard local Tesseract discovery, an offline guide, third-party notices and
a component inventory. The first real Windows runs exposed an incorrect test
expectation for the vendor version label, a Unicode image-path failure in OCR,
and ZIP filename normalization hiding malformed names. Those were corrected
before the successful Windows run.

The final source passed 219 tests on Windows with one POSIX-only skip and 219
tests on Mac with seven Windows-only skips. The extracted Windows application
initialized its native window and rendered its bundled 512-field catalog.
Packaged tests exercised five actual scanned fixtures, custom masks, reviewed
patient bundles and independently reopened spreadsheet exports. See
[the delivery record](../testing/WINDOWS_BUILD.json) and [test scope](../TESTING.md).

The release is a private, unsigned prototype. A complete person-driven Windows
laptop trial and live REDCap import remain open. The PACE patient review row
still requires a separately validated conversion for repeating instruments.
No research dataset, patient record, held-out test input, camera or LLM was used.
