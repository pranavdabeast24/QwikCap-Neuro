Answer keys are read only by the comparison step, after extraction; they are never app input. The test split has already been used and cannot support a fresh held-out accuracy claim.

Run the focused fictional acceptance gate with a configured Python environment:

```sh
python tools/verify_pace_auto.py --output verification/pace-auto
```

Add `--bundle path/to/QwikCap.app` on Mac or `--bundle path/to/QwikCap` on Windows to run PDF, bundle and spreadsheet jobs through the packaged companion. This gate uses separately generated fictional examples; it does not replace the supplied-packet replay.

Replay the supplied packet from the repository root. Use a new output folder for each run:

```sh
python tools/replay_pace_packets.py --split train --output verification/clinic-train
python tools/replay_pace_packets.py --split test --output verification/clinic-test
```

Add `--packet sih-synthetic` to select the earlier printed packet. All keys stay separate from app inputs.

## What remains outside this check

Real handwriting, changed or unknown layouts, camera capture, live REDCap import, existing-record updates and a simultaneous 500-patient batch are unvalidated. Incorrect sticker OCR cannot yet be manually adjudicated into a different patient group; it remains blocked. Projects and exports are not encrypted. The app keeps the existing memory/file bounds and requires review before export.
